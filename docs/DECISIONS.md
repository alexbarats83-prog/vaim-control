# Технические решения

| Решение | Причина |
| --- | --- |
| Flask и серверный Jinja2 | Один HTTP-сервис, формы и контроль прав без отдельного фронтенд-сервиса. |
| SQLite в разработке и PostgreSQL в облаке | Быстрый локальный запуск и поддержка конкурентных транзакций в рабочей среде. |
| Целые денежные единицы | Одинаковая точность двух знаков на обеих СУБД. |
| Версионирование счёта и снимок маршрута | Защита от повтора устаревшей формы и изменений шаблона во время согласования. |
| «Согласован» в аудите | Завершённый маршрут сразу передаёт счёт в очередь бухгалтерии, сохраняя момент согласования. |
| Серверная доставка закрытых файлов | Права доступа проверяются при каждом скачивании. Секрет Storage остаётся на сервере. |
| Идемпотентный идентификатор платежа и уникальный номер в рамках счёта | Повтор формы или номера поручения не создаёт второй платёж. |
