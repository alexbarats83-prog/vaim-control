# Архитектура

Приложение создаётся фабрикой `vaim.create_app`. Gunicorn загружает `wsgi:app`. Flask Blueprints охватывают аутентификацию, рабочую область, счета и администрирование. Новые модули подключаются через отдельные Blueprints и регистрируют свои права, операции и события.

Сервер рендерит Jinja2-шаблоны. Bootstrap 5.3.8 включён локально с лицензией MIT. JavaScript управляет мобильным меню и порядком этапов в форме. Обработчики Flask проверяют данные, полномочия и версию записи.

## Переходы счёта

```text
Черновик → На согласовании → Согласован → Ожидает оплаты → Частично оплачен → Оплачен
                       │                          └───────────────────────────→ Оплачен
                       ├─→ На доработке → На согласовании (новый цикл)
                       └─→ Отклонён
Черновик / На доработке → Отменён
```

Состояние «Согласован» фиксируется событием в той же транзакции, которая переводит счёт в очередь оплаты. Каждый цикл сохраняет название, версию и упорядоченные этапы маршрута. Изменения шаблона действуют при следующей отправке. Актуальная принадлежность к роли проверяется на каждом этапе. Просрочка вычисляется относительно московской даты.

Группировка сумм на главной и в отчётах выполняется по валютам. Количество полностью оплаченных счетов относится к дате, когда сумма платежей достигла суммы счёта. Остатки и текущие статусы отражают момент запроса.
