# База данных

| Таблица | Назначение |
| --- | --- |
| `users`, `roles`, `user_roles` | Сотрудники, роли и их связи. Версия сессии позволяет отзывать доступ после редактирования или блокировки. |
| `counterparties` | Контрагент с уникальной парой ИНН и КПП. |
| `routes` | Настраиваемый маршрут, номер его версии и порядок этапов. |
| `invoices` | Реквизиты, текущий цикл, позиция этапа, состояние, оплаченная сумма и версия записи. |
| `approval_runs` | Снимок маршрута на момент отправки. Ключ — счёт и номер цикла. |
| `payments` | Платежи. Уникальны ключ запроса и нормализованный номер поручения в рамках счёта. |
| `attachments` | Метаданные документов счёта или платежа и случайный ключ закрытого объекта. |
| `audit_events` | Действие, исполнитель, время, ссылка на счёт и детали. |

Суммы и НДС хранятся целыми числами `BIGINT` с масштабом 2. Ограничения базы контролируют положительную сумму и максимальный остаток. Для событий используется UTC. Интерфейс показывает московское время.

В SQLite включены внешние ключи. Первичная миграция создаёт схему и семь базовых ролей. Перед запуском выполните `python -m flask --app vaim db upgrade`.
