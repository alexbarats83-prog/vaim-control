# Разработка VAIM Control

- Работайте из корня текущей рабочей копии. Отделяйте новые бизнес-модули на уровне Flask Blueprint. Переиспользуйте авторизацию, аудит и правила доступа из `vaim/access.py`.
- Для изменения моделей добавляйте миграцию Alembic. Проверяйте миграции на пустой SQLite-базе и в тестовом PostgreSQL.
- Храните суммы целыми числами в минимальных денежных единицах. Всегда учитывайте валюту при агрегации.
- Проверяйте право на операцию и видимость объекта на сервере. Для изменений счёта проверяйте версию и сохраняйте связанные изменения и аудит одной транзакцией.
- Тестируйте изменения через обычные HTTP-маршруты. Сохраняйте включённую CSRF-защиту и используйте отдельное окружение для демонстрации.
- Выполняйте `python -m pytest -q`. Для проверки PostgreSQL задайте `VAIM_TEST_POSTGRES_URL` на выделенную базу.
- Не помещайте секреты и реальные документы в Git. Не запускайте промышленное развёртывание без согласования.
