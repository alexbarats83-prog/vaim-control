# История версий

## 0.1.2

- Используется серверный ключ Supabase `sb_secret_` в заголовке `apikey`. Для проверки роли `anon` поддерживается ключ `sb_publishable_`.
- Bucket по умолчанию и в Render переименован в `documents`. Обновлены инструкция перехода и тесты Storage.

## 0.1.1

- Добавлены общие для всех процессов ограничения попыток входа и отзыв сессии при выходе.
- Самосогласование требует разрешения конкретного этапа. Добавлены проверки параллельных согласований и неизменности согласованного счёта.
- PostgreSQL работает в закрытой схеме `vaim` по TLS. Адаптер Storage проверяет приватность bucket при загрузке и скачивании.
- Добавлены команды проверки PostgreSQL и реального Supabase Storage с очисткой тестового файла.
- Конфигурация Render адаптирована к Free. Документированы внешние миграции и создание первого администратора.

## 0.1.0

- Добавлены авторизация, семь ролей, управление сотрудниками и реестр контрагентов.
- Реализованы счета, закрытые вложения, настраиваемые маршруты и история согласования.
- Добавлены частичная и полная регистрация оплаты, аудит, задачи и отчёты.
- Подготовлены миграция, автоматические тесты, Dockerfile и конфигурация Render.
